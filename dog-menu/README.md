# 🐶 The Daily Bowl

A formal meal request form, submitted daily by the dog to management (the humans).

He is a foodaholic. He likes to sleep. He has demands. This is his menu.

## How to view it on your phone

It's a single `index.html` with no build step, so any of these work:

- **GitHub Pages (easiest):** in this repo's *Settings → Pages*, set the source to the
  `main` branch (root). Once it deploys, the menu lives at
  `https://susangadegone.github.io/susangadegone/dog-menu/` — bookmark it or add it to
  your home screen.
- **Anywhere else:** just open `index.html` in any browser. No server needed.

## Features, per the chef

- Breakfast, People Food Tax, Treats, Dinner, and Beverages courses
- Tap items, then **Ring the dinner bell 🔔** to submit the order to management
- Tap the chef's name to set it to his real name (saved on your device)
- Live status ticker (spoiler: he is hungry and/or asleep)
